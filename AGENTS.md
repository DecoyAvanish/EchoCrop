# Fine Print X-Ray project guidance

Read `docs/PRODUCT_STANDARD.md` before changing product behavior or design. The user's October 2026 review sets the continuing priorities: trustworthy real-input analysis, a complete phone flow, accessible interactions, actionable reports, and calm visual polish.

Preserve the cyan/ink palette, mono instrument UI, and tactile paper. Every contract clause must remain accessible in Reading view. Never call unmatched text safe or present a pattern match as a calibrated probability. Keep parsing and document state on the device; document text belongs only in tab-scoped session storage, never in a URL, analytics, logs, or a remote service.

Run relevant regression tests for analysis or money calculations, then `npm run typecheck` and `npm run build`. Describe the browsers and audit modes actually tested. Do not invent user research, claim perfect accessibility, or publish unmeasured performance scores.
